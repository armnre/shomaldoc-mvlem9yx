# شمال‌داک (ShomalDoc)

سامانهٔ یکپارچهٔ مدیریت فرآیند پایان‌نامهٔ دانشگاه شمال آمل — از ثبت موضوع تا دفاع و صدور صورتجلسه.

## امکانات
- ورود با نام کاربری/رمز (هش PBKDF2)، قفل موقت پس از تلاش ناموفق، مدیریت نشست‌ها
- نقش‌ها: دانشجو، استاد، مدیر گروه، تحصیلات تکمیلی، امور مالی، داور، مدیر سیستم (چندنقشی)
- موضوع، انتخاب استاد راهنما با کنترل ظرفیت، تأیید گروه و مشاور
- پیشینه و پروپوزال نسخه‌بندی‌شده با زنجیرهٔ تأیید قابل‌تنظیم
- ایرانداک، تصویب نهایی، ترم‌ها، تمدید و کمیسیون موارد خاص
- نسخهٔ نهایی، همانندجویی، داوری چنددوره‌ای، زمان‌بندی دفاع و صورتجلسهٔ PDF
- اعلان‌های درون‌سامانه‌ای، گزارش‌ها و نمودارها، ثبت کامل رویدادها

## ساختار
- `apps/app/src` — رابط کاربری React (RTL، واکنش‌گرا)
- `apps/app/src/api` — endpointهای سمت سرور
- `apps/app/src/lib/server.ts` — منطق مشترک: احراز هویت، RBAC، گردش‌کار
- `packages/components` — کامپوننت‌های مشترک (shadcn/ui)

ساخته‌شده با ZiteJS (React + Vite + Tailwind).
